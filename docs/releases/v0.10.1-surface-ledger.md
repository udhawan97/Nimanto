Keyboard-save focus also has a real WebKit regression: a disabled submit
control can remain active until a deferred blur. The restoration guard handles
that captured control while respecting focus moved elsewhere. The Career Ledger
journey checks both Add activity and Save answer with a bounded focus assertion;
a test-only suppressed-restoration probe must still fail that assertion.

## Publication gates

The candidate must pass repository CI and independent source review. Inspect
the full CodeQL analysis and record each remaining finding's disposition;
successful execution alone is insufficient. Refresh Graphify and verify a
scoped query before tagging. Confirm main ancestry, the annotated release tag,
downloaded inventories and checksums, and the deployed Pages identity.

## Limits and rollback

Source checks and browser evidence do not certify hosted operation, every
operating system, VoiceOver, or signed native distribution. The HTTPS socket
probe uses disposable certificates and an explicit test-only loopback
substitution; it does not establish an external-provider integration. No
candidate profiles or real external actions are used for acceptance.

The source release carries no schema change from v0.10.0. Stop services and
preserve the complete data directory before updating; restore that stopped
copy or fix forward. Do not replay an ambiguous external action. Restoring a
pre-deletion backup can resurrect deleted data, as documented in the recovery
plan.
