# Governance

Nimanto is maintained by Umang Dhawan. Maintainer approval is required for source
rights, security boundaries, scoring rules, employment or immigration language,
external actions, release artifacts, and changes to the product contract.

Architecture decisions are recorded in repository documentation. Security reports
use the private process in `SECURITY.md`; routine product work uses GitHub issues and
pull requests. Maintainers may reject changes that increase automation breadth
without a matching permission, evidence, and rollback design.
