# Nimanto v0.5.5 — Same Boundaries, Fresh Runtime

v0.5.5 is a source-distributed local-beta maintenance release. It updates the
locked Fastify runtime from 5.12.0 to
[5.12.1](https://github.com/fastify/fastify/releases/tag/v5.12.1), an upstream
security-maintenance release, and regenerates the governed public screenshots, dependency
inventories, and checksums from that exact source tree. It introduces no Nimanto
feature, schema migration, provider, hosted service, model, submission channel,
external-action authority, or network surface, and it leaves Nimanto's network
configuration unchanged.

## Improved

- Fastify moves to 5.12.1 in the API's locked production dependency graph.
- The public screenshot evidence manifest and captures are regenerated after the
  dependency change; visual comparison remains bounded by the repository's exact
  source/asset checks.
- CycloneDX and SPDX inventories, their checksum manifest, versioned public
  links, operations guidance, notices, and runtime identities now describe one
  v0.5.5 source release.

## Verify

Use Node.js 24–26 and pnpm 11 from a clean checkout of the exact tag:

```bash
corepack enable
pnpm install --frozen-lockfile
pnpm check
pnpm build
pnpm test:e2e
pnpm screenshots:check
pnpm audit --audit-level high
pnpm licenses:check
pnpm sbom:check
pnpm release:check
```

The browser gate runs nineteen sequential WebKit journeys across the public
site, private workspace, session boundaries, draft preservation, packet
currentness, accessibility recovery, and narrow-screen layout.

Download these three release assets into one empty directory:

- [CycloneDX inventory](https://github.com/udhawan97/Nimanto/releases/download/v0.5.5/nimanto-v0.5.5.cdx.json)
- [SPDX inventory](https://github.com/udhawan97/Nimanto/releases/download/v0.5.5/nimanto-v0.5.5.spdx.json)
- [SHA-256 manifest](https://github.com/udhawan97/Nimanto/releases/download/v0.5.5/nimanto-v0.5.5-SHA256SUMS.txt)

Then run:

```bash
shasum -a 256 --check nimanto-v0.5.5-SHA256SUMS.txt
```

The checksum manifest covers exactly the CycloneDX and SPDX files. GitHub
generates the tag ZIP and tar archives; the manifest does not authenticate those
archives, and Nimanto ships no signed installer or desktop binary.

## Upgrade

Stop Nimanto and copy the complete `.nimanto-data/` directory. Then check out
the exact tag, reinstall the locked graph, and start the local beta:

```bash
git checkout v0.5.5
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

v0.5.5 makes no schema change. Existing v0.5.4 workspaces remain on additive
schema version 4. A stopped full-directory backup remains required because the
beta does not guarantee downgrade compatibility. Workspaces upgrading from
v0.5.3 or earlier receive the schema-v4 packet-generation migration documented
in the [operations guide](https://github.com/udhawan97/Nimanto/blob/v0.5.5/docs/operations/local-beta.md#upgrade-to-v055).

## Boundaries

- This is a candidate-controlled local beta, not employer screening or a hiring
  probability estimate.
- Matching remains deterministic and evidence-linked; imported claims remain
  pending until the candidate confirms them.
- Packets require assurance and approval. External effects require the current
  packet, separate action approval, and the live runtime switch.
- Local receipts are not proof that an employer received anything.
- Connected-account sending, a hosted backend, signed desktop packaging,
  notarization, and automatic updates remain outside this release.
