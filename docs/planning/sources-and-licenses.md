# Nimanto sources, licenses, and provider gate

**Evidence snapshot:** 2026-08-05 15:52 CDT  
**Scope:** pre-implementation planning for a free/open-source-first, H-1B-focused job-discovery and review-first application-packet product.  
**Status language:** **Source-checked** means supported by the linked primary source at this snapshot. **Proposed** is an architecture choice, not implemented or approved. Package versions are discovery pins, not a claim that a compatible lockfile or vulnerability audit exists.

## Gate outcome

**Proposed:** retain the TypeScript modular-monolith direction: Next.js web/PWA, Fastify API, one PostgreSQL database, a `pg-boss` worker, S3-shaped object storage, Better Auth, deterministic scoring, and an optional model-provider adapter. Business rules, evidence provenance, authorization, and action approvals must remain framework-independent.

The stack is viable, with these corrections:

1. **Defer USAJOBS ingestion.** Its API terms limit data to the registered company's stated use and prohibit derivative works. Nimanto should use an ordinary outbound link or user-supplied text unless OPM gives written approval for the exact normalization, storage, and display plan.
2. **Keep infrastructure bounded.** Use SeaweedFS as the reviewed S3-compatible Compose/self-host adapter and R2 only as the hosted adapter; do not add a third storage implementation. Prometheus, Grafana, Tauri, email sending, and LanguageTool remain later gates. Slice 1 is passkey-first because verified-email delivery is explicitly deferred; the invitation itself is the pre-auth registration context, and recovery must be accepted before beta.
3. **Do not treat “public GET” as redistribution or submission permission.** Greenhouse, Lever, and Ashby endpoints are board/company-scoped. Discover only user-selected/curated boards, retain bounded snapshots, preserve source links, and deep-link to the provider-hosted application.
4. **Prefer reproducible datasets.** Import versioned O*NET downloads rather than its always-latest web service. Store every government source period, row/layout version, retrieval time, and transformation version.
5. **Treat fresh dependencies cautiously.** Several pins are very recent. Select exact pins only after a clean compatibility/security smoke matrix; commit a lockfile, SBOM, notices, and migration artifacts.

No hiring-probability, guaranteed-ATS, or “will sponsor” claim is supportable. Historical filings and petition decisions are dated evidence; models may extract and draft, but deterministic code and explicit user approval control scores, factual claims, and external actions.

Every adapter must declare `discovery_only`, `deep_link`, `form_assist`, `authorized_api_submit`, or `authorized_email_send`; store source URL/ID, retrieved/source timestamps, content hash, parser version, observed policy version, expiry/tombstone, and capability; block private/link-local URL retrieval, redirect escapes, oversized/active content, auth bypass, CAPTCHA bypass, and prompt instructions embedded in postings. A domain enters URL retrieval only through a platform-owned approval recording terms/data-rights and applicable robots review, named approver/date, allowed uses, budgets and kill switch; applicable robots directives are honored. Tenant policy may only narrow that approval.

Slice-1 Greenhouse policy: fixed official host; curated/user-selected board token; one concurrent request per tenant, at most 60/hour/board; up to three `429`/`5xx` retries honoring `Retry-After` with jitter; no retry for other `4xx`; five-minute list cache; transient list body deleted after per-job split and within one hour; tenant-private raw job JSON retained 30 days after last seen; normalized frozen version/tombstone retained until user deletion. No raw or normalized content is cross-tenant reused, publicly redistributed, used for training, or placed in fixtures. Terms review date is 2026-08-05; a per-source kill switch stops refresh without deleting the user's normalized history. A manually supplied private original URL is provenance only and never becomes a deep link before provider review permits it.

## Accessibility implications

Target WCAG 2.2 AA ([Recommendation](https://www.w3.org/TR/WCAG22/)) from the first fixture. Use native controls and visible labels; keyboard-complete import, evidence editing, scoring, review, export, and approval; persistent focus and programmatic async status; text alternatives for charts; never encode supported/missing/blocker/confidence by color alone; respect zoom, reflow, contrast, high-contrast, reduced motion, and timeout needs. Passkeys need an accessible fallback and recovery path.

Generated application artifacts are inspected/reported for semantic headings, logical reading order, extractable text, meaningful links, tagged-PDF accessibility, contrast, Letter/A4 reflow, and a conservative single-column alternative. Extractability, parity, overflow and links are initial gates. Grammar, exported-document contrast, accessibility tagging, widows/orphans, and subjective visual quality remain advisory until a versioned measured method and threshold promotes them; every advisory needs resolution or a named final-approver waiver. Axe automation is not a substitute for VoiceOver/NVDA, keyboard, zoom, and cognitive/error-recovery review.

## High-star inspiration boundary

Official GitHub API snapshots on 2026-08-05 show that [Career Ops](https://api.github.com/repos/santifer/career-ops) (MIT), [Reactive Resume](https://api.github.com/repos/AmruthPillai/Reactive-Resume) (MIT), [AI Job Search](https://api.github.com/repos/MadsLorentzen/ai-job-search) (MIT), and [Resume Matcher](https://api.github.com/repos/srbhr/Resume-Matcher) (Apache-2.0) each exceeded 10,000 stars. That threshold is only a dated ecosystem signal. They are inspiration for review-first posture, portable resume data, archived inputs/outputs, and explainable matching—not dependencies or copied implementations. No code has been copied.

If reuse is proposed later, record the exact upstream commit, license and notices, transitive dependencies, security posture, source/API rights, and a feature-level reason. Stars are dated ecosystem signals, not selection criteria. AGPL/source-available job agents and scraping adapters remain reference-only unless a separate license and data-rights review approves the exact boundary.

## Post-approval Slice-1 gates

After the exact implementation approval—not before—Slice 1 must run the dependency compatibility/security/license lockfile review; generate SBOM/notices; create the specified synthetic/adversarial fixtures; and enforce provider-term or government-layout drift as a kill-switch event. These are implementation gates, not additional authorization phrases.
