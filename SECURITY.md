# Security policy

Nimanto handles private career and application data. Please do not open a public
issue for a suspected vulnerability or include real résumés, credentials, tokens,
or provider data in a report.

Use GitHub's private vulnerability reporting for this repository. Include the
affected version, a minimal synthetic reproduction, impact, and any proposed
mitigation. Reports are acknowledged as capacity allows; no response-time promise
is made for this beta.

The local beta is not approved for multi-user hosted production. External actions
ship disabled, cloud-model fallback does not exist, and provider credentials must
remain outside the repository and database. See [the trust plan](docs/planning/trust-and-security.md).
