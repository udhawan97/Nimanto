# Nimanto Domain Language

Nimanto is a candidate-controlled workspace that turns reviewed career evidence into inspectable application decisions without screening candidates or predicting hiring outcomes.

## Evidence and explanation

**Evidence Claim**:
A candidate-visible career statement with provenance, a locator, and an explicit pending, confirmed, rejected, or superseded state.
_Avoid_: Fact, extracted truth

**Profile Version**:
An immutable candidate-approved snapshot of confirmed Evidence Claims and exact authorization wording.
_Avoid_: Current profile, résumé state

**Match Publication**:
An immutable deterministic explanation produced from one exact Profile Version, one exact role snapshot, and one rule version.
_Avoid_: Score, prediction, recommendation

**Dataset Edition**:
One checksum-addressed historical government evidence source with its period, transformation identity, and review provenance.
_Avoid_: Sponsorship truth, current employer policy

## Preparation and action

**Packet**:
A frozen candidate artifact set prepared for one application from confirmed evidence.
_Avoid_: Submission, application send

**Assurance Run**:
An immutable review of one exact Packet artifact set whose findings either pass or block approval.
_Avoid_: Approval, guarantee

**Action Intent**:
The exact Packet, implementation, target, and payload a candidate may separately approve before any local handoff is attempted.
_Avoid_: Send permission, standing approval

## Operations

**Discovery Schedule**:
A candidate-owned recurring request to refresh one approved public job-board source and publish deterministic role explanations.
_Avoid_: Auto-apply, background agent

**Deletion Run**:
A resumable erasure record that distinguishes revoked database access from unfinished local file cleanup and final completion.
_Avoid_: Delete request, completed deletion
