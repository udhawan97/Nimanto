# Nimanto v0.1.0 — local beta

## First release

Nimanto's first public beta closes the candidate-side loop from evidence intake to an approval-gated local handoff.

### Included

- local tenant, session, and evidence vault;
- bounded UTF-8 TXT, Markdown, JSON, OOXML DOCX, and text-layer PDF evidence import with active-content, page, size, and prohibited-document rejection;
- email-bound, hashed, expiring, revocable, single-use local/self-hosted invitations alongside the private launcher path;
- deterministic explainable matching and blocker detection;
- Greenhouse, Lever, Ashby, and manual role intake;
- disabled-by-default exact-host HTTPS role intake with terms-review metadata, pinned public DNS, redirect/private-network rejection, and transient-body deletion;
- historical H-1B evidence with limitations;
- default-disabled employer resolution with a server-owned reviewed-corpus gate reporting precision, recall, abstention, predicted positives, unique fixtures, and a 95% interval;
- application and candidate-outcome tracking;
- grounded shared JSON/TXT plus synchronized modern and ATS-safe DOCX/PDF packet generation;
- packet assurance and candidate approval;
- deterministic document filename/hash, critical-text round-trip, PDF page/blank/metadata, and synchronized-format checks;
- optional exact-tag/digest Ollama review that fails approval closed when configured and unavailable, with no cloud fallback;
- user-opened deep-link and local test-outbox verification seams; no connected-account sending;
- separate action approval and reset-on-restart runtime switch;
- portable JSON export and cascaded local deletion;
- optional loopback-only Ollama draft seam;
- responsive static website and installable web shell.

### Release gates

The tag is created only after the locked checks, production build, WebKit candidate journey, responsive/console review, artifact signatures and hashes, Graphify refresh/query, dependency and secret audits, and two-round council review all pass from the final tree.

### Locally verified from the release tree

- `pnpm check`: formatting, spelling, type checks, and the complete unit/integration suite passed;
- `pnpm test:e2e`: production build plus two real WebKit journeys passed (private launcher and single-use invitation);
- GitHub Pages build: `/Nimanto` asset paths and setup-directed hosted calls to action passed;
- document assurance: all six packet artifacts, SHA-256, critical-text round trips, PDF structure/metadata, and modern/ATS parity passed on the synthetic fixture;
- `pnpm audit --prod --audit-level high`: no known vulnerabilities;
- CycloneDX 1.6 and SPDX 3.0.1 repository dependency inventories generated from the final lockfile and the reproducible SBOM completeness check passed;
- Graphify incremental update contains more than 900 architecture nodes, and the evidence-to-action scoped query passed.

The digest-pinned Docker image is built as a required GitHub CI job because Docker is not available in the release workstation. The release is not tagged until that remote build and the other required workflows pass.

### Deliberate beta limits

- no hosted candidate backend;
- no public sign-up, passkey, recovery, or production multi-tenant identity;
- no production OAuth connector onboarding;
- no Apple notarization, Windows signing, or embedded desktop backend;
- no legal-advice or sponsorship guarantee;
- no employer screening or hiring-probability use.

The static website is public. Candidate data remains in the local API data directory by default.
